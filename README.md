# ربات مدیریت و رشد کانال موزیک — Music Home

## چیکار می‌کنه؟

**پردازش موزیک:**
- اسم خواننده/آهنگ دست‌نخورده می‌مونه؛ فیلد Album/Comment به اسم و لینک کانال تغییر می‌کنه.
- واترمارک روی کاور آلبوم.
- امضای خودکار `@musichome58` زیر کپشن هر پست کانال.

**رشد کانال:**
- **دکمه‌ی اشتراک‌گذاری** زیر هر پست — یه تپ، پیام آماده برای فوروارد به تلگرام باز می‌شه.
- **سیستم دعوت (بدون جایزه):** هر کاربر با `/invite` یه لینک اختصاصی می‌گیره؛ ربات تعداد جوین‌های واقعی از اون لینک رو می‌شماره (`/myinvites` برای خودش، `/topinviters` برای ادمین).
- **پیام خوش‌آمد:** وقتی کسی از طریق لینک دعوت جوین کانال می‌شه، ربات سعی می‌کنه پیام خوش‌آمد خصوصی بفرسته (⚠️ تلگرام فقط اجازه می‌ده اگه اون کاربر قبلاً یه‌بار با ربات چت رو استارت کرده باشه — محدودیت خود تلگرامه، نه ربات).
- **حالت اینلاین:** توی هر چتی تایپ کن `@نام‌ربات اسم‌آهنگ`، آرشیو کانال سرچ می‌شه و می‌تونی مستقیم بفرستیش — دیده‌شدن کانالت رو جاهای دیگه هم می‌بره بالا.

**تولید محتوا:**
- **صف پیشنهاد آهنگ** از اعضا (با تأیید/رد ادمین).
- **کشف موزیک آزاد (Creative Commons)** با `/discover <ژانر>` از Jamendo.

## مراحل راه‌اندازی

### ۱. توکن و آیدی
- توکن از `@BotFather`.
- آیدی عددی خودت از `@userinfobot`.
- کلاینت آیدی Jamendo از https://developer.jamendo.com/v3.0

### ۲. فعال‌سازی حالت اینلاین (مهم!)
توی `@BotFather`:
```
/setinline
```
و یه متن پیش‌فرض برای جست‌وجو انتخاب کن (مثلاً "اسم آهنگ رو بنویس...").

### ۳. نصب و اجرا
```bash
pip install -r requirements.txt
export BOT_TOKEN="..."
export ADMIN_CHAT_ID="..."
export JAMENDO_CLIENT_ID="..."
python bot.py
```

### ۴. دسترسی‌های ادمین ربات توی کانال
موقع ادمین کردن ربات توی `t.me/musichome58`، این‌ها رو حتماً فعال کن:
- **Edit Messages** — برای اصلاح خودکار پست‌های جدید
- **Post Messages** — برای پست از صف پیشنهاد و /discover
- **Invite Users via Link** — برای ساخت لینک‌های دعوت اختصاصی

## دستورات

| دستور | کاربر | کارکرد |
|---|---|---|
| `/start` | همه | راهنما |
| `/invite` | همه | ساخت لینک دعوت اختصاصی |
| `/myinvites` | همه | دیدن تعداد دعوت‌های خودش |
| `/discover <ژانر>` | فقط ادمین | جستجوی موزیک آزاد |
| `/topinviters` | فقط ادمین | لیست برترین دعوت‌کننده‌ها |

فایل موزیک فرستادن توی پی‌وی: اگه ادمینی بلافاصله پردازش می‌شه؛ اگه عضو عادی‌ای، به‌عنوان پیشنهاد برای ادمین می‌ره.

## داده‌های ذخیره‌شده
دو فایل کنار `bot.py` ساخته می‌شن (نه توی حافظه، پس با ری‌استارت پاک نمی‌شن):
- `catalog.json` — آرشیو آهنگ‌های پست‌شده، برای حالت اینلاین
- `referrals.json` — لینک‌های دعوت و شمارش‌شون

## محدودیت‌ها
- پیام خوش‌آمد فقط برای کسایی می‌ره که قبلاً با ربات چت رو استارت کرده باشن (محدودیت تلگرام).
- کاور OGG واترمارک نمی‌خوره.
- ربات باید ۲۴ ساعته یه‌جایی اجرا بشه (VPS، Railway، Render یا سیستم همیشه‌روشن با systemd/screen).
